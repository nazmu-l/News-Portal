# News Portal Website Structure (6 Pages)<br>

Requirements of website: 6 Page website 
a. Homepage Page: <br>
i. Header Top Section (Email, Phone Number, Facebook, Twitter, LinkedIn, YouTube Link)<br>
ii. Navigation Section with Logo, Home, About, Category (National, Politics, Sports, Education, Entertainment etc.), Author, Contact, Reporter Login page link.<br> 
iii. Breaking News Section (jQuery News Ticker Plugin, Full wide, Add minimum three news with sliding) <br>
iv. One Lead News Section Left Part, Selected Four News Section in Right Side. v. Latest News Section (using bootstrap card)<br>
vi. National News Section (using bootstrap card) <br>
vii. Education News Section (using bootstrap card)<br>
viii. Big Footer Section ix. Footer Section. <br><br>

b. About Page: 
i. Breadcrumb Section. <br>
ii. Editor Speech Section. <br>
iii. Advertisement Policy Section. <br>
iv. News Policy Section. <br>
v. Administrative Staff Section. (using bootstrap card) <br><br>

c. Category Page:
i. Breadcrumb Section. <br>
ii. Category News Section. (using bootstrap card) <br>
iii. Advertisement Section. <br>
iv. Category News Section. (using bootstrap card) <br>
v. Pagination Section. <br><br>

d. Author Page: 
i. Breadcrumb Section. <br>
ii. Editor Speech Section. <br>
iii. Senior Reporter Section. (using bootstrap card) <br>
iv. General Reporter Section. (using bootstrap card) <br><br>

e. Contact Page: 
i. Breadcrumb Section. <br>
ii. Direct Contact Information Section. <br>
iii. Send Message Form Section. (Name, Email, Mobile, Message) <br>
iv. Google Map API Section. <br><br>

f. Login Page: 
i. Breadcrumb Section. <br>
ii. Login Form Section. (User Name, Password) <br><br>

Full container wide navigation menu with mouse hover effect. 
Confirmation popup window when submit the login form.
Current Date & Time Using JavaScript. 
Include External CSS & JavaScript file. 
Internal Pages Linking. 
All the page must be responsive in all device.
